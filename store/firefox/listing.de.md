Add under "Manage translations" → Deutsch. The extension's own interface is English only, so this text describes what it recognises, not a German interface.

LocalApply – Bewerbungen privat ausfüllen

## Summary (233 / 250 characters)

```
Füllt Bewerbungsformulare mit einem Klick aus deinem gespeicherten Profil: Kontaktdaten, Adresse, Links, Gehaltsvorstellung, Eintrittstermin und Lebenslauf. Versteht 8 Sprachen. Kein Konto, keine KI, keine Daten verlassen dein Gerät.
```

## Description

```
Bei jeder Bewerbung tippst du dieselben Angaben neu ein. LocalApply speichert sie in einem Profil und füllt das geöffnete Bewerbungsformular mit einem Klick aus. Du prüfst das Formular und schickst es selbst ab.

<b>Was ausgefüllt wird</b>
<ul>
<li>Name, E-Mail, Telefon (auch mit Ländervorwahl-Auswahl), Adresse und Geburtsdatum</li>
<li>LinkedIn-, GitHub-, Xing- und Portfolio-Links</li>
<li>Gehaltsvorstellung, Kündigungsfrist, frühester Eintrittstermin und Berufserfahrung</li>
<li>Fragen zu Arbeitserlaubnis, Visum und Umzugsbereitschaft</li>
<li>Aktuelle Position, Arbeitgeber und Ausbildung</li>
<li>Lebenslauf und Anschreiben als Datei sowie Anschreiben als Text</li>
<li>Deine eigenen Antworten auf wiederkehrende Fragen wie „Wie sind Sie auf uns aufmerksam geworden?"</li>
</ul>
<b>Funktioniert dort, wo du dich bewirbst</b>
Füllt Formulare auf Greenhouse, Ashby, Personio, Recruitee, Teamtailor und gewöhnlichen Karriereseiten von Unternehmen aus und unterstützt zusätzlich Workday, Lever, SmartRecruiters, SAP SuccessFactors und LinkedIn Easy Apply. Feldbezeichnungen werden auf Deutsch, Englisch, Französisch, Spanisch, Italienisch, Niederländisch, Portugiesisch und Polnisch erkannt.

<b>So funktioniert es</b>
<ol>
<li>Gib deine Daten einmal auf der Profilseite ein.</li>
<li>Klicke in einer Bewerbung auf das Symbol in der Symbolleiste, drücke Alt+Umschalt+F oder nutze die Schaltfläche „Fill application", die auf unterstützten Jobportalen erscheint.</li>
<li>Ausgefüllte Felder werden grün umrandet. Pflichtfelder, die offen bleiben, werden gelb umrandet und im Pop-up aufgelistet. Dort kannst du eine Antwort für das nächste Mal speichern.</li>
</ol>
<b>Privat von Grund auf</b>
<ul>
<li>Profil und Dokumente liegen nur in Firefox auf deinem Rechner.</li>
<li>Kein Konto, kein Server, keine KI, keine Statistik. Das Add-on stellt keine Netzwerkverbindungen her.</li>
<li>Es klickt nie auf „Absenden" oder „Weiter" und setzt keine Einwilligungshäkchen.</li>
<li>Felder, die du schon ausgefüllt hast, bleiben unverändert.</li>
<li>Exportiere dein Profil als Datei oder lösche alles mit einem Klick.</li>
</ul>
<b>Warum Zugriff auf alle Websites nötig ist</b>
Bewerbungsformulare liegen auf Tausenden verschiedener Domains, oft in eingebetteten Frames. Deshalb muss LocalApply Formularfelder auf jeder Seite ausfüllen können. Es liest oder ändert ein Formular nur, wenn du auf Ausfüllen klickst.
```
