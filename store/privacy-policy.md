# LocalApply privacy policy

Neither store requires a privacy policy for LocalApply, because it collects no user data. Use this text if you want to publish one anyway (for example on a project page linked from the listings).

```
LocalApply does not collect, transmit or share any data.

Your profile, documents and saved answers are stored in your browser's extension storage on your own device. They are written into web forms only when you click Fill, press the keyboard shortcut or use the Fill button on a job site.

The extension makes no network requests, loads no remote code and contains no analytics or tracking.

You can export your data to a file or delete all of it at any time from the profile page. Removing the extension also deletes its storage.
```
