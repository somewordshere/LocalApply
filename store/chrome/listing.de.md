# Chrome Web Store listing (Deutsch)

The Chrome Web Store offers per-language listings only for extensions that ship translations (`_locales/` in the package). LocalApply does not yet, so this text is ready for when the extension's interface is localised. Until then, publish the English listing only.

## Description

```
Bei jeder Bewerbung tippst du dieselben Angaben neu ein. LocalApply speichert sie in einem Profil und füllt das geöffnete Bewerbungsformular mit einem Klick aus. Du prüfst das Formular und schickst es selbst ab.

WAS AUSGEFÜLLT WIRD
• Name, E-Mail, Telefon (auch mit Ländervorwahl-Auswahl), Adresse und Geburtsdatum
• LinkedIn-, GitHub-, Xing- und Portfolio-Links
• Gehaltsvorstellung, Kündigungsfrist, frühester Eintrittstermin und Berufserfahrung
• Fragen zu Arbeitserlaubnis, Visum und Umzugsbereitschaft
• Aktuelle Position, Arbeitgeber und Ausbildung
• Lebenslauf und Anschreiben als Datei sowie Anschreiben als Text
• Deine eigenen Antworten auf wiederkehrende Fragen wie „Wie sind Sie auf uns aufmerksam geworden?"

FUNKTIONIERT DORT, WO DU DICH BEWIRBST
Füllt Formulare auf Greenhouse, Ashby, Personio, Recruitee, Teamtailor und gewöhnlichen Karriereseiten von Unternehmen aus und unterstützt zusätzlich Workday, Lever, SmartRecruiters, SAP SuccessFactors und LinkedIn Easy Apply. Feldbezeichnungen werden auf Deutsch, Englisch, Französisch, Spanisch, Italienisch, Niederländisch, Portugiesisch und Polnisch erkannt.

SO FUNKTIONIERT ES
1. Gib deine Daten einmal auf der Profilseite ein.
2. Klicke in einer Bewerbung auf das Symbol in der Symbolleiste, drücke Alt+Umschalt+F oder nutze die Schaltfläche „Fill application", die auf unterstützten Jobportalen erscheint.
3. Ausgefüllte Felder werden grün umrandet. Pflichtfelder, die offen bleiben, werden gelb umrandet und im Pop-up aufgelistet. Dort kannst du eine Antwort für das nächste Mal speichern.

PRIVAT VON GRUND AUF
• Profil und Dokumente liegen nur in deinem Browser auf deinem Rechner.
• Kein Konto, kein Server, keine KI, keine Statistik. Die Erweiterung stellt keine Netzwerkverbindungen her.
• Sie klickt nie auf „Absenden" oder „Weiter" und setzt keine Einwilligungshäkchen.
• Felder, die du schon ausgefüllt hast, bleiben unverändert.
• Exportiere dein Profil als Datei oder lösche alles mit einem Klick.

WARUM ZUGRIFF AUF ALLE WEBSITES NÖTIG IST
Bewerbungsformulare liegen auf Tausenden verschiedener Domains, oft in eingebetteten Frames. Deshalb muss LocalApply Formularfelder auf jeder Seite ausfüllen können. Es liest oder ändert ein Formular nur, wenn du auf Ausfüllen klickst.
```
