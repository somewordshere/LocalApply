# LocalApply 0.3.0

Released 2026-10-16.

### Added

- The profile page takes the phone number either as country code and number in two boxes, or as one full number such as +48791532218. A full number is split into code and number, so forms that ask either way are still filled.

### Changed

- Dates go into forms as DD-MM-YYYY when neither the field nor the page shows which order it expects (was YYYY-MM-DD). Native date pickers still get the ISO date they require.
